## Лабораторная работа "Решение задачи регрессии с помощью нейронных сетей"

## Структура репозитория

- `lab6Lite.ipynb` –  ноутбук для задания Lite: создание и сравнение 6 архитектур нейронных сетей на числовых данных из таблицы HeadHunter, проведены эксперименты с гиперпараметрами и проанализировано влияние архитектурных решений на качество моделей
- `lab5Pro.ipynb` – ноутбук для задания Pro: обучение модели на данных баскетбольных матчей и достижение MAE ≤ 17 очков.
- `lab5Ultra_Pro.ipynb` – ноутбук для задания Ultra Pro: обучение модели для определения авторства текстов 20 русских писателей. Подготовка корпуса, обучение классификатора и проверка на собственном тексте с интерпретацией результата.
- `lab5Pytorch.ipynb` – ноутбук для задания Lite: построение модели для предсказания цен автомобилей (ЮЛА), разделив данные на train/test/val, оценив MAE на проверочной выборке и вычислив относительную ошибку в процентах.
## Требования

Для запуска ноутбуков рекомендуется использовать **Google Colab**. Все необходимые библиотеки предустановлены в Colab.
